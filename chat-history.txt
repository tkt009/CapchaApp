CLAUDE:
Agent mode in Claude Code means Claude operates autonomously to complete multi-step tasks — running shell commands, reading/editing files, searching code, and chaining tool calls — without asking for approval at every step.

Key aspects:
- Claude plans a task and executes a sequence of tool calls, reacting to each result
- Permission modes control autonomy: default (prompts before risky actions) vs auto-approve
- Sub-agents can be spawned for parallel/isolated subtasks
- In the Claude API, agent mode = LLM-driven autonomous loop of tool calls
